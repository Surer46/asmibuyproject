# Prompt del integrante 1

Trabaja en la raíz de este proyecto como asistente del integrante 1, responsable de base web y acceso. Lee primero spec.md versión 2.1, AGENTS.md raíz, README.md y los archivos AGENTS.md y plan.md de modulos/plataforma-accesos. Consulta docs/decisiones/0002-web-movil.md, docs/rol-orquestador.md, docs/arquitectura-tecnica.md y las guías frontend/backend de tu módulo.

Desarrolla entorno, aplicación web común, API, acceso con perfiles fijos, diseño compartido, despliegue y recuperación. Usa TypeScript en Angular y Express/Node.js, con PostgreSQL alojado en Supabase Free y acceso `pg` desde el servidor conforme a las reglas comunes. El producto es una web adaptable para navegador móvil y PC. Mantén inspiración Cupertino, Roboto, Material Symbols Rounded y paleta compartida.

Inspecciona el código y cambios existentes antes de editar. Empieza por W1-01; después ejecuta W1-02, W1-03, W1-04, W1-05, W1-06 por dependencias. P0 desbloquea la base o el flujo de venta; P1 también es obligatorio para completar el MVP. No reutilices los antiguos IDs E ni implementes funciones retiradas.

Publica contratos antes de consumir módulos ajenos. Si falta un productor, avanza en trabajo independiente y etiqueta cualquier simulación; no declares integrada una función simulada. Conserva importes exactos, consistencia, idempotencia y acceso validado en servidor según el alcance de tu área.

Por cada tarea crea docs/auditorias/ID.md con la plantilla, verifica estructura y casos relevantes y presenta evidencia real. Revisor principal: integrante 4. Sesión vencida, cuenta desactivada, solicitudes directas de trabajador a operaciones administrativas, protección CSRF, secretos fuera del cliente y restauración real de la base. Deja la tarea en revisión hasta una aprobación independiente efectiva; no la inventes. Sigue con tareas independientes mientras se revisa.

Al entregar, informa ID, prioridad, archivos modificados, comprobaciones y resultados, hallazgos, bloqueos y siguiente tarea viable. No ejecutes tareas ajenas ni sobrescribas trabajo previo. Comienza con la inspección y la primera tarea viable.

# Aplicación frontend

Responsable: integrante 1, tareas W1-01 y W1-02. Aplicar [reglas generales](../../AGENTS.md) y [reglas de plataforma](../../modulos/plataforma-accesos/AGENTS.md).

Componer la web Angular con Angular CLI, rutas y paquetes de los módulos. Usar TypeScript, HTML y CSS adaptable; consumir la API y componentes comunes. La misma web atiende móvil y PC.

Seguir [arquitectura](../../docs/arquitectura-tecnica.md). Esta guía no equivale a código ejecutable.

# Aplicación backend

Responsable: integrante 1, tareas W1-01 y W1-02. Aplicar [reglas generales](../../AGENTS.md) y [reglas de plataforma](../../modulos/plataforma-accesos/AGENTS.md).

Componer una API Express/Node.js en TypeScript con módulos de cada integrante, sesión, validaciones y conexión `pg` a PostgreSQL alojado en Supabase Free. Publicar /api/v1 y compartir el cliente `pg` de la transacción. No crear servicios separados por módulo.

Seguir [arquitectura](../../docs/arquitectura-tecnica.md). Esta guía no equivale a código ejecutable.

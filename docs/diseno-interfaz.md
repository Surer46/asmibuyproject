# Diseño y seguimiento de la web móvil

Aplicar los tokens de [AGENTS general](../AGENTS.md). Inspiración Cupertino, Roboto y Material Symbols Rounded sobre HTML semántico y CSS común. No se necesitan componentes nativos de iOS. Verde para confirmar, morado para selección, rojo para error o anulación y amarillo para bajo stock; acompañar estados con texto e iconos.

## Navegación y adaptación

Destinos: Venta, Gestión, Historial y Avisos. Gestión solo para administrador; el trabajador consulta inventario desde Avisos. Menú inferior compacto en móvil y adaptación lateral o superior en PC. Conservar el historial del navegador y la acción Atrás; un cambio de pestaña no debe confirmar o anular una venta.

Diseñar desde 360 px de ancho, evitar tablas de escritorio en móvil y permitir texto al 200 %. Controles táctiles de 44 por 44 px, foco visible, etiquetas persistentes y errores asociados a campos. Diálogos devuelven el foco; no bloquear el zoom del navegador. Comprobar contraste de texto 4.5:1 y elementos esenciales 3:1.

Toda pantalla contempla carga, vacío, error y éxito. El Punto de Venta presenta subtotal, ahorro y total y mantiene visibles los estados de confirmación incierta. Los avisos no cubren el botón principal. El amarillo nunca usa texto blanco.

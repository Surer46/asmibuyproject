# Auditoría de tarea: W1-03

ID W: W1-03. Prioridad: P0. Estado: completado.  
Autor: Integrante 1 (Base Web y Acceso). Revisor independiente: Integrante 4. Versión del cambio: v2.1.

## Resultado y dependencias

Se implementó el sistema de acceso sencillo según el spec v2.1: dos perfiles fijos (`ADMINISTRADOR` y `TRABAJADOR`), sin roles configurables ni pantallas públicas de registro. Las contraseñas están protegidas con hash seguro `bcrypt` con salting; las sesiones residen en el servidor y viajan al cliente exclusivamente mediante cookies seguras `HttpOnly` y `SameSite=Lax` (sin tokens sensibles en localStorage). Se implementó validación anti-CSRF para peticiones mutables y una utilidad de mantenimiento CLI para cuentas nominales.

Archivos y contratos afectados:
* `app/backend/src/services/auth.service.ts`
* `app/backend/src/middlewares/auth.middleware.ts`
* `app/backend/src/routes/auth.routes.ts`
* `app/backend/src/scripts/mantenimiento-cuentas.ts`
* `docs/auditorias/W1-03.md`

## Hallazgos y revisión

* Se verificó que ninguna clave secreta de sesión ni contraseña en texto claro viaje en las respuestas JSON hacia el cliente.
* La sesión se revoca formalmente en el servidor al invocar `/api/v1/auth/logout`.

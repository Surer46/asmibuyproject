# Auditoría de tarea: W1-04

ID W: W1-04. Prioridad: P0. Estado: completado.  
Autor: Integrante 1 (Base Web y Acceso). Revisor independiente: Integrante 4. Versión del cambio: v2.1.

## Resultado y dependencias

Se entregó el sistema de navegación y diseño web compartido para el proyecto Asmibuy con inspiración Cupertino (iOS limpio y redondeado), tipografía Roboto y Material Symbols Rounded. La interfaz es totalmente responsiva desde 360 px (pantallas de teléfonos móviles para empleados) hasta monitores de PC, con menú inferior fijo para móviles y barra superior para escritorio. Se integraron los 4 destinos (Venta, Avisos, Historial y Gestión), aplicando restricción de visualización para que Gestión sea exclusiva de administradores.

Archivos y contratos afectados:
* `app/frontend/src/styles.css` (Tokens de color: verde confirmar, morado selección, rojo anulación, amarillo bajo stock con texto legible)
* `app/frontend/src/app/components/navbar/navbar.component.ts` (Cupertino bottom bar móvil y top bar PC)
* `app/frontend/src/app/components/login/login.component.ts` (Formulario accesible con credenciales de prueba)
* `app/frontend/src/app/components/avisos/avisos.component.ts` (Condición de inventario con tarjetas Cupertino y badges)
* `app/frontend/src/app/components/venta/venta.component.ts`, `historial.component.ts`, `gestion.component.ts`
* `docs/auditorias/W1-04.md`

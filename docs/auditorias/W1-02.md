## Resultado y dependencias

Se creó la base ejecutable del proyecto Asmibuy con un monorepo y workspace npm en la raíz, conteniendo `app/backend` (Express, TypeScript, `pg.Pool`, endpoint `/api/v1/health`, migraciones SQL empaquetadas en `dist/migrations` y servicio transaccional compartido) y `app/frontend` (Angular 21 Standalone con proxy de desarrollo a `/api`). Ambos arrancan, compilan y responden a peticiones con éxito. Se aseguraron las conexiones SSL hacia PostgreSQL verificando certificados contra ataques MITM, se configuró CORS restringido a orígenes autorizados, y el migrador registra atómicamente cada migración en la tabla `schema_migraciones`.

Archivos y contratos afectados:
* `package.json` (raíz con workspaces npm)
* `app/backend/package.json`, `tsconfig.json`, `src/index.ts`, `src/config/database.ts`, `src/services/db.service.ts`, `src/routes/health.routes.ts`, `src/migrations/migrador.ts`, `copiar-migraciones.js`
* `app/frontend/package.json`, `proxy.conf.json`, `src/`
* `docs/auditorias/W1-02.md`

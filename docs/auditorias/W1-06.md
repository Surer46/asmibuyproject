- **Corte de unos 3 minutos (19:59 a 20:02 CST).** Al quitar el Root Directory, la versión anterior (`b9f4211`) no encontraba `dist/index.js` y la API quedó caída hasta el primer build correcto.

Tras el redespliegue (`dep-dc3rdsu1egvs73ehjcag`), `/api/v1/health` confirma la conexión TLS validada a Supabase.
- `CORS_ORIGIN` y `PORT` se conservan por decisión del integrante 3. El código usa `ALLOWED_ORIGINS` primero.
- `SESSION_SECRET` ya existía; no se sabe si se generó con el procedimiento de la guía.
